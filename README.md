--DESCRIPCIÓN DEL PROYECTO--
El proyecto consiste en una plataforma web exclusiva para estudiantes, diseñada para facilitar la compra, venta e intercambio de materiales académicos y tecnológicos que ya no utilizan, como Arduino, protoboards, sensores, calculadoras, cascos de realidad virtual, libros o herramientas. La plataforma busca ayudar a los estudiantes a conseguir materiales a precios más accesibles, fomentar la reutilización y ofrecer mayor seguridad mediante verificación de estudiantes, transacciones intermediadas y puntos de encuentro públicos para realizar las entregas.
